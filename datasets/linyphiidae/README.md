Place one folder per expert-confirmed genus here, with photographs inside.
Choose this directory in the app's Genus Dataset tab to audit and export an
inventory. Record specimen IDs before splitting data for training and testing.

Review the exported CSV and fill every specimen_id before using Train Model.
All views of one specimen need the same ID, unique across the dataset. At least
three distinct specimens per genus and two genera are required to run the
pipeline; substantially more data is needed for meaningful evaluation.
